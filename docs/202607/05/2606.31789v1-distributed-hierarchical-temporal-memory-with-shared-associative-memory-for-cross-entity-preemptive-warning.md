## 摘要
多变量时间序列的异常检测在大规模分布式系统中仍然是一个关键挑战，其中相关实体在异常发生前可能表现出可迁移的前兆行为。现有方法通常独立处理每个数据流，因此本质上是被动的。为了解决这一局限性，我们提出了分布式层次时间记忆（D-HTM），这是一种神经形态框架，通过共享联想记忆（SAM）实现跨实体预防性预警。D-HTM结合了空间池化器（SP），将观测投影到共同的稀疏分布式表示（SDR）空间；时间记忆（TM）模块，在线学习实体特定的动态；以及共享联想记忆，存储反复出现的前兆特征。通过在相关实体间重用前兆知识，D-HTM可以在局部异常发生前发出预警，同时保留HTM的在线学习能力。我们在服务器机器数据集（SMD）、土壤湿度主动被动（SMAP）数据集、火星科学实验室（MSL）数据集以及为隔离前兆迁移而设计的合成级联基准上评估了D-HTM。实验结果表明，D-HTM在保持竞争性被动异常检测性能的同时，实现了有效的跨实体预警传播。在真实世界数据集中，D-HTM在异常发生前平均提供了8.1个样本的预警提前时间。这些发现表明，可迁移的前兆结构可以在共享的SDR空间中出现，并可用于生成预防性预警，将HTM从孤立的被动检测扩展到分布式预测推理。

## Abstract
Anomaly detection in multivariate time series remains a critical challenge in large-scale distributed systems, where related entities may exhibit transferable precursor behavior prior to anomaly onset. Existing methods typically operate independently on each data stream and therefore remain fundamentally reactive. To address this limitation, we introduce Distributed Hierarchical Temporal Memory (D-HTM), a neuromorphic framework that enables cross-entity preemptive warning through a Shared Associative Memory (SAM).   D-HTM combines a Spatial Pooler (SP) that projects observations into a common Sparse Distributed Representation (SDR) space, Temporal Memory (TM) modules that learn entity-specific dynamics online, and a Shared Associative Memory that stores recurring pre-anomaly signatures. By reusing precursor knowledge across related entities, D-HTM can issue warnings prior to local anomaly onset while preserving HTM's online learning capabilities.   We evaluate D-HTM on the Server Machine Dataset (SMD), the Soil Moisture Active Passive (SMAP) dataset, the Mars Science Laboratory (MSL) dataset, and a synthetic cascade benchmark designed to isolate precursor transfer. Experimental results demonstrate effective cross-entity warning propagation while maintaining competitive reactive anomaly detection performance. Across the real-world datasets, D-HTM provides an average warning lead time of 8.1 samples prior to anomaly onset.   These findings demonstrate that transferable precursor structure can emerge within a shared SDR space and be reused for preemptive warning generation, extending HTM beyond isolated reactive detection toward distributed predictive reasoning.

现有的大规模分布式系统（如服务器集群、航天器遥测）中，异常检测方法通常独立处理每个数据流，即使相关实体间存在可迁移的前兆行为也无法利用，导致系统只能被动响应异常。本文试图解决的核心问题是：**如何让分布式实体在保持在线学习能力的同时，共享跨实体的前兆知识，实现异常发生前的预防性预警。** 研究背景引入人脑新皮质的层次时间记忆（HTM）模型，其具有持续在线学习无需重训练的优势，但传统部署中每个HTM代理隔离运行，缺乏跨实体知识共享。本文提出D-HTM框架，将HTM从孤立反应检测扩展到分布式预测推理。

## 2. 方法论

### 核心思想
利用共享稀疏分布式表示（SDR）空间实现跨实体可比性，通过共享联想记忆（SAM）存储和检索重复出现的前兆激活模式，使一个实体学到的前兆知识能被其他相关实体用于提前预警。

### 关键技术细节
- **表示对齐**：对每个实体独立进行z-score归一化（式1），消除操作点偏差；所有实体共用同一个空间池化层（Shared Spatial Pooler），将归一化输入映射到相同的SDR空间（固定1024列，4%稀疏性），保证相似输入产生重叠SDR。
- **共享联想记忆（SAM）**：存储前兆窗口 \(W_j = \{s_{t-L}, ..., s_{t-1}\}\)，附带重复计数 \(n_j\) 和最近访问时间 \(t_j\)。当本地HTM检测到异常时，将前L个SDR模式存入SAM（重复则计数+1）。
- **预警生成**（算法1）：在线推理时，每个实体构建当前查询窗口 \(Q_t\)，与SAM中每条记忆逐位置比较，若至少K个位置满足重叠≥τ（式5、6），则发出预防性预警，无需等待本地异常分数达到阈值。
- **记忆管理**：采用重复计数+最近访问的淘汰策略，达到容量时移除低频旧记忆。

## 6. 主要结论与发现

1. **共享SDR空间可使前兆结构跨实体迁移**，通过共享SP实现表示对齐后，不同实体的相似行为能产生重叠SDR。
2. **D-HTM在保持竞争性反应检测的同时实现预防性预警**：在真实数据集上平均提前8.1个样本（SMD 3.42, SMAP 6.87, MSL 7.21, 合成11.36）。

4. **匹配比K/L=0.60能最佳平衡精度与召回**，回看窗口L需根据数据集动态特性选择。
5. **预警生成依赖于有意义的前兆结构**而非随机SDR重叠（打乱后F1降至0.05）。

## 7. 优点

- **在线与无重训练性**：保留HTM的连续在线学习能力，无需离线重训练。
- **跨实体知识共享机制新颖**：不同于传统参数聚合（FL）或模型复制，采用记忆检索方式在推理时传播前兆，不干扰本地学习。
- **表示对齐设计精巧**：z-score归一化+共享SP解决了异构实体间直接比较的偏差。
- **鲁棒性验证全面**：包括回看窗口、匹配阈值、打乱控制等多种灵敏度分析，证明方法稳定。
- **生物可解释性与可扩展性**：基于神经形态计算，适合分布式部署，内存管理机制支持长期运行。

## 8. 不足与局限

- **固定回看窗口与简单匹配**：采用固定L和硬阈值重叠匹配，缺乏自适应窗口或概率置信度估计，可能漏掉变长或弱前兆。
- **共享SP冻结**：部署后无法调整SDR表示，若分布漂移会导致检索性能下降。
- **实验覆盖有限**：仅评估4个数据集，且合成数据集人工设计可能过度乐观；未在真实工业级大规模分布式系统（如物联网、云数据中心）中验证。
