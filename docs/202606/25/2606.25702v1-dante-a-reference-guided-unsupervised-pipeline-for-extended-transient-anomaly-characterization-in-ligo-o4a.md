## 摘要
在第四次观测运行（O4）期间分析引力波探测器数据需要稳健的方法来区分平稳仪器噪声与非平稳瞬变（毛刺）。在这项工作中，我们提出了DANTE（域自适应网络用于瞬态评估），这是一个完全无标签的流水线，旨在发现和分类新型非平稳伪迹。我们证明，将预训练的视觉变换器（DINOv2）适配为从时频谱图中提取局部块嵌入，可以实现瞬态异常的高分辨率映射。通过控制注入测试，我们形式化了信号稀释屏障，表明虽然多实例学习（MIL）Top-k池化恢复了扩展拓扑，但它对亚秒级形态是盲目的。为了应对小样本分类的不稳定性，我们引入了一个自适应狄利克雷过程混合模型（DPMM），该模型动态选择协方差结构。最后，通过实现原生O4a背景重新校准，我们解决了域偏移问题，证明了与普遍假设的一致性，即广泛的O4a形态（最初被历史参考标记为新颖）是平稳伪迹。我们得出结论，无监督异常检测严格需要原生重新校准来过滤域偏移伪迹，而对剩余未建模单例的明确分类则需要多通道验证。

## Abstract
The analysis of gravitational-wave detector data during the fourth observing run (O4) requires robust methods to distinguish stationary instrumental noise from non-stationary transients (glitches). In this work, we present DANTE (Domain-Adaptive Network for Transient Evaluation), a pipeline designed to discover and triage novel non-stationary artifacts entirely without labels. We demonstrate that adapting a pre-trained Vision Transformer (DINOv2) to extract local patch embeddings from time-frequency spectrograms allows for high-resolution mapping of transient anomalies. We formalize the Signal Dilution Barrier via controlled injection tests, showing that while Multiple Instance Learning (MIL) Top-k pooling recovers extended topologies, it is blind to sub-second morphologies. To address small-sample taxonomy instability, we introduce an adaptive Dirichlet Process Mixture Model (DPMM) that dynamically selects covariance structures. Finally, by implementing a native O4a background recalibration, we resolve the domain-shift problem, demonstrating consistency with the hypothesis that pervasive O4a morphologies (initially flagged as novel by historical references) are stationary artifacts. We conclude that unsupervised anomaly detection strictly requires native recalibration to filter domain-shift artifacts, while definitive classification of remaining unmodeled singletons requires multi-channel validation.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：LIGO第四轮观测运行（O4）期间，引力波探测器数据中普遍存在非平稳仪器噪声瞬变（glitches），这些瞬变与真实的引力波信号在时频形态上重叠，严重干扰搜索与参数估计。传统的监督分类方法（如Gravity Spy）受限于标注数据集的拓扑边界，对新型或罕见瞬变识别能力有限；而现有无监督方法常因**域偏移**（instrumental upgrades between O3b and O4a）引入大量伪发现。
- **目标**：设计一个完全无标签的流水线，能够在O4a数据中自主发现并分类扩展时长（>1秒）的未建模瞬态异常，同时通过背景重新校准区分真实异常与域偏移伪影。
- **背景意义**：这是首次在LIGO O4a连续数据流上部署端到端的无监督异常检测与分类系统，为后续多通道物理验证提供了高置信度的候选集，并揭示了域偏移导致的系统性误判问题。

## 2. 方法论：核心思想、关键技术细节、算法流程
### 核心思想
采用**参考引导+多实例学习（MIL）+自适应聚类+原生校准**四层架构：
1. **检测层**：使用冻结的DINOv2视觉Transformer从Q-变换时频谱图中提取局部块嵌入，通过Top-k多实例学习聚合最异常块的得分，克服全局[CLS]标记的信息稀释效应。
2. **分类层**：对异常候选的384维MIL特征向量进行自适应PCA降维后，使用狄利克雷过程混合模型（DPMM）自动确定簇数，并根据样本量动态选择协方差结构（full/tied/diag），解决小样本下的协方差病态问题。
3. **跨会话连接**：通过单链接层次聚类和余弦相似度阈值（ρtrans=0.75），在连续384维空间中关联不同观测会话的异常，实现宏观族系识别。
4. **域偏移解析**：构建原生O4a背景索引（150,000个严格筛选的纯噪声段），将候选异常重新评分，以过滤域偏移引起的伪异常。

### 关键技术细节
- **特征提取**：使用dinov2_vits14_reg（ViT-S/14 + 寄存器标记），输入518×518像素的时频谱图，产生37×37=1369个14×14的补丁，每个补丁提取384维向量并L2归一化。
- **参考索引**：基于Gravity Spy O3b标注数据构建281个聚类质心作为初始参考；另构建独立O4a原生索引（1216个质心）用于域偏移校准。
- **MIL Top-k评分**：对每个补丁计算与参考质心的最大余弦相似度，选择最不相似的k=68个补丁（约5%），取其平均的1减去相似度作为段级异常分数S_MIL。
- **自适应DPMM**：根据n<100跳过PCA/DPMM（标记为孤立单例）；n≥100时动态保留解释90%方差的PCA维度（至少20维）。协方差类型：n≥200用full，50≤n<200用tied，n<50用diag。浓度参数α=0.01促进稀疏成分。
- **跨探测器符合否决**：对每个候选在合作探测器±2秒窗口内提取MIL特征，若余弦相似度S_coh > τ_coh（由广义帕累托分布估计的99.9%分位数0.9750），则标记为符合/潜在天体物理，否则确认为局部仪器异常。

## 3. 实验设计：数据集、基准、对比方法
- **数据集**：
  - **O4a生产数据**：GWOSC公开存档，LIGO Hanford（H1）和Livingston（L1），GPS区间[1,368,973,312, 1,384,525,312]（约180天/237天子集）。经数据质量过滤后，72个有效会话（约20%占空比），共214,092个32秒段。
  - **O3b参考索引**：用Gravity Spy O3b公开标签目录（23类形态，包括“无毛刺”）。
  - **Mock Data Challenge（MDC）**：在两个阶段注射合成瞬态形态：
    - Phase 1（基线证伪）：8类通用形态（Blip, KoiFish, Scratchy等），1,417次注入，验证全局[CLS]标记的失效。
    - Phase 2（MIL验证）：7类形态（Blip, AsymBlip, SpiralBurst, ScatteredLight, HarmonicComb, KoiFish, Whistle）注入真实O4a噪声，每个形态100次独立试验，测试不同信噪比（匹配滤波器SNR约200-430）下的召回率。
- **基准**：以全局[CLS]池化方法作为基线（Phase 1）；无监督假正率固定为1%（经验P99阈值）。
- **对比方法**：未直接与其他无监督管道进行端到端定量比较（如VAE、HDBSCAN等），但在讨论中定性对比了Gravity Spy（监督）和自监督全局池化ViT的局限性。主要对比是全局vs局部MIL架构。

- **硬件**：NVIDIA A100（SM 80）或V100（SM 70）GPU；使用torch.inference_mode()和cuDNN自动调优。
- **框架**：PyTorch 2.1.1+cu118，CUDA 11.8，cuDNN 8.7.0，Python 3.10；scikit-learn 1.3.2。
- **推理批次**：每批32个时频谱图（GPU）或16个（CPU）。
- **未说明的总训练时长/GPU小时数**：仅提及DINOv2模型冻结（无需训练），生产扫描跨越180天数据，但未报告具体计算耗时。MDC部分也未报告注入实验的耗时。

## 5. 实验数量与充分性
- **检测层**：在72个会话、214,092个段上运行，提取140个候选异常。进行了多阶段过滤（形态比对、重复消除）。MDC共两个阶段：Phase 1含1,417次注入，Phase 2每个形态100次独立试验（95%置信区间），总计约700次注入（7形态×100）。
- **分类层**：对140个候选进行自适应DPMM聚类（依据n≥100的44个会话分析稳定性的自举平均调整兰德指数）。
- **消融研究**：
  - **Top-k池化尺度消融**（k∈{16,32,68,128,256,512,1369}），验证信号稀释。
  - **族系恢复的阈值敏感性**（ρtrans ∈ {0.60, 0.75, 0.90}）。
  - **DPMM浓度参数α**（{0.001, 0.01, 0.1, 1.0}）。
  - **背景索引污染测试**（注入人工形态到O4a索引，验证无吸收）。
- **充分性**：实验覆盖了检测、分类、域偏移解析三个主要环节，采用了严格的统计方法（威尔逊区间、自举、极值理论）。但缺乏与其他无监督方法（如VAE+HDBSCAN）的定量比较，且仅在一个数据集（O4a子集）上验证。MDC中SNR远高于真实天体物理信号（~10-30），可能高估对强信号的检测能力，对弱信号的推广性存疑。

## 6. 主要结论与发现
1. **信号稀释屏障**：全局[CLS]池化对亚秒级瞬变（Blip）召回率为0%，而MIL Top-k能够恢复扩展瞬变（>1秒，如HarmonicComb召回率>98%）。
2. **域偏移解析**：使用O3b索引发现的140个候选中有123个属于Family 03，11个属于Family 01。原生O4a重新校准后，Family 01完全坍塌（0幸存），Family 02/03仅保留53个分散候选，无任何结构完整的宏观族系存活。这表明初始识别的“新形态”实质上是O4a的普遍平稳特征（域偏移伪影）。
3. **孤立极端事件**：3个单例幸存于原生背景，具有高度非结构化的时频形态，与已知硬件注入或天体物理事件无关联。
4. **探测器不对称性**：L1检测到136个候选，H1仅4个（34:1），与Livingston环境退化一致。
5. **方法学关键**：无监督异常检测必须进行原生背景重新校准以过滤域偏移；剩余未建模单例需要多通道辅助数据验证。

## 7. 优点
- **方法创新**：将DINOv2的局部补丁嵌入与MIL Top-k池化结合，首次在GW领域有效缓解了全局池化的信号稀释；引入自适应PCA+DPMM解决小样本高维协方差病态；采用单链接聚类利用“链接效应”识别域偏移导致的漂移流形（而非人工分割）。
- **统计严谨性**：所有阈值（检测、符合、流动性）均基于经验极值统计（非参数P99、GPD拟合、自举置信区间），避免参数假设偏差。
- **工程完备性**：设计了SWMR HDF5存档、状态恢复、批量GPU推理、SHA-256校验、结构化日志等生产级架构，确保可再现性。
- **可解释性**：通过激活图、MDC召回曲线、Tail QQ图、自举稳定性分析等提供了对算法行为的深入理解。

## 8. 不足与局限
- **检测盲区**：管道对亚秒级瞬变（Blip等）完全失效，且固定k=68导致尺度偏差，无法自适应捕获不同持续时间形态。
- **实验对比不足**：未与其他无监督基线（如VAE、Isolation Forest、HDBSCAN+UMAP）在同一设置下定量比较，无法充分说明相对优势。
- **MDC信噪比尺度过高**：注入SNR（200-430）远超真实天体物理信号（~10-30），结果不能直接推广至弱信号检测性能。
- **数据集有限**：仅使用O4a子集（约180天），且完全依赖应变数据，未利用辅助物理环境监测（PEM）通道。剩余单例的物理起源无法区分。
- **原生索引污染风险**：若未标记的微弱异常持续足够长时间（≥观测期的5%），可能被K-means吸收，导致对这些异常的“再识别”失效。作者承认这是参考引导架构的内在歧义。
- **计算开销**：尽管强调效率，但未报告运行180天数据的具体GPU时数；实时部署需额外范式。
- **形态稳定性依赖于随机种子**：K-means和DPMM的随机初始化虽通过种子固定确保可再现，但未评估种子选择对结果的影响（仅少量敏感性实验）。
