## 摘要
计算机视觉数据集中普遍存在标注错误，这些错误会显著降低基于这些数据集训练的系统的性能，尤其是在目标检测等复杂任务中。目前存在多种识别标注错误的方法，包括免训练的特征空间方法，该方法能够快速且可解释地分析标注。然而，对于包含语义和空间信息的目标检测标注，其行为仍 largely 未被探索。
   在这项工作中，我们分析了基于特征空间的方法在检测目标检测数据集标注错误中的适用性。通过调整一种现有的特征空间方法，我们证明了这类方法能够可靠地暴露语义误标，而位置错误则仍然难以检测。我们使用VOC2012和KITTI数据集，跨多个预训练嵌入模型、合成噪声类型（对称、非对称和位置噪声）以及真实世界的标注错误评估了这种行为。
   所有代码和真实世界错误均可从以下仓库公开获取：https://github.com/ChristianSieberichs/BoundingBox_corruption_detection

## Abstract
Annotation errors are widespread in computer vision datasets and can significantly degrade the performance of systems trained on them, particularly in complex tasks such as object detection. Several approaches exist to identify annotation errors, including training-free feature-space methods which provide a fast and interpretable way to analyze annotations. However, the behavior on object detection annotations, which include semantic and spatial information, remains largely unexplored.   In this work we analyze the applicability of feature-space-based approaches for detecting annotation errors in object detection datasets. By adapting an existing feature-space method, we show that such approaches reliably expose semantic mislabel, while positional errors remain difficult to detect. We evaluate this behavior across multiple pretrained embedding models, synthetic noise types (symmetric, asymmetric, and positional), and real-world annotation errors using VOC2012 and KITTI.   All code and real-world corruptions are publicly available at the following repository: https://github.com/ ChristianSieberichs/BoundingBox\_corruption\_detection

- **核心问题**：免训练的特征空间方法能否有效检测目标检测数据集中的各类标注错误？其检测能力受哪些因素影响（噪声类型、嵌入模型、数据集结构等）？

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：利用预训练图像嵌入模型（如 ResNet-34、CLIP、DINO 等）为每个目标实例（边界框区域）提取特征向量；通过分析特征空间中样本与其 k 近邻的标签一致性来识别潜在错误：若实例的标签与邻居的多数标签不一致，则认为该实例可能是错误的。
- **关键技术细节**：
  1. **实例级处理**：对每个边界框区域进行裁剪，独立提取特征（避免图像内多目标干扰）。
  2. **SimiFeat-R 变体**：计算每个实例的**标签分布**（k=10 近邻的类别频率），与实例自身标签的 one-hot 向量计算余弦相似度作为**质量得分**（得分越低说明越可能错误）。
  3. **阈值设定**：使用 **HOC（High-Order Consensus）** 估计器，通过假设近邻标签一致性来推断每个类别的干净样本比例，从而得到每个类别的独立阈值。
  4. **噪声类型**：考虑语义错误（对称/非对称标签替换）和位置错误（通过 IoU 控制偏移程度），此外还分析了真实数据集中的自然错误。
- **公式**：余弦相似度 Score = (ŷ_n · e_j) / (‖ŷ_n‖₂·‖e_j‖₂)，其中 ŷ_n 是邻居标签分布归一化向量，e_j 是实例自身标签的 one-hot 向量。

### 6. 论文的主要结论与发现

1. **语义错误可被可靠检测**：对标签噪声（尤其是对称噪声），F1 随噪声率上升接近 0.95（VOC2012 40% 噪声下）。
2. **位置错误检测困难**：即使高噪声率（40%）+ 强偏移（IoU=0.2），最大 F1 仅约 0.4，远低于语义错误。
3. **嵌入模型影响检测偏向**：强语义聚类模型（如 DINOv2）对语义错误敏感但对位置错误不敏感；ResNet-34 则相反。
4. **类不平衡破坏 HOC 估计**：在 VOC2012 上，非对称噪声导致大量 Person 被标记为 Potted plant，HOC 错误估计各类的错误比例，造成严重假阳性（F1 在噪声率>10% 后下降并稳定在 0.6）。
5. **真实数据中存在大量错误**：KITTI 中通过人工检查发现 1,722 个唯一错误（1,195 个误标、197 个定位错误），其中大部分来自 Don't Care 类（589/655）。
6. **低噪声率下性能退化是普遍问题**：所有模型在噪声率 <5% 时 F1 均 <0.5，假阳性主导，且在训练依赖方法中也有类似观察。

### 7. 优点：方法或实验设计上的亮点

- **免训练、高效率**：无需额外训练，几分钟内可处理数万边界框，适合大规模数据集初筛。
- **可解释性**：通过近邻标签分布提供直观判定依据。
- **系统分析位置噪声**：将位置噪声独立参数化（噪声率 + 偏移强度），并首次揭示特征空间方法在定位错误上的局限性。
- **提供真实错误标注和代码**：公开清洗后的 VOC2012 和 KITTI 的标注错误分片，便于后续研究。
- **跨模型对比**：涵盖 CNN（ResNet）和 ViT（CLIP、DINO）多种架构，分析不同特征表示的影响。

### 8. 不足与局限

- **对位置错误不敏感**：由于特征提取器倾向于保持语义一致性，小范围边界框偏移难以改变特征空间位置，导致漏检。
- **低噪声率下假阳性高**：HOC 倾向于高估错误比例，在干净或近乎干净的数据上反而产生大量误报。
- **受类不平衡严重**：HOC 假定近邻标签一致性，在长尾数据中估计不准确，导致非对称噪声下性能崩溃。

- **无法检测漏标（overlooked）**：方法基于已有标注，对无标注框的错误完全失效。
- **人工验证的主观性**：KITTI 中错误分类（截断/遮挡/正确）存在一定主观判断，可能引入偏差。
